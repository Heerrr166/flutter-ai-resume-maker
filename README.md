# AI Resume Maker

Build a resume that gets noticed. A Flutter + Node.js/Express resume builder with hybrid AI: Gemini-powered writing, job-match analysis, and resume tailoring, backed by a local resume intelligence engine (ATS scoring, job-description keyword matching, skill recommendations) that every AI feature gracefully falls back to if Gemini is unavailable or unconfigured.
